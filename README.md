# ZAUS Arquitetura e Engenharia

Este repositório contém uma página estática para apresentação dos serviços da ZAUS. Foi adicionada uma seção interna para controle de tarefas seguindo o sistema de Delegação 3P (Pessoas, Processos e Painéis).

## Novos Arquivos
- **automation.js**: gera checklists dinâmicos para Atendimento, Projetos e Marketing.
- **README.md**: explica a estrutura e as funcionalidades incluídas.

## Como usar
Abra `index.html` em um navegador. Na seção **Painel Interno - Delegação 3P** será exibida uma lista de tarefas para cada área. As tarefas podem ser marcadas conforme forem concluídas.
